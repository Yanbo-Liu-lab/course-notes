## 这份总结的做法

没有套用“核心目标／定义／假设／方程／边界条件／定理／解法／例题／易错点／结论”的固定十板块，而是**为每章单独写一份大纲**，按该章知识自身的逻辑展开：概念从哪里来、要解决什么问题、怎么用、适用边界在哪里。

例如：

- 第二章围绕“外力 → 一点的应力 → 应力张量 → 主应力 → 平衡方程”这条分析链组织；
- 第四章从“单向拉伸试验如何推广到三向应力状态”切入，再走“最一般形式 → 小变形线性 → 各向同性”的简化链；
- 第七章先论证“为什么要换极坐标”，再解释极坐标方程里 `1/ρ` 项和 `(σρ−σφ)/ρ` 项的几何来源，避免死记附加项。

每章都要求：公式、定理、结论注明适用前提（小变形、线弹性、各向同性、平面应力/应变、单连通等），不把特定条件下的结论当普适结论。

具体的提示词、各章大纲、生成脚本和排版流水线在 [`../方法与工具/`](../方法与工具/)。

## 阅读建议

0. 在仓库根目录跑 `bash site.sh serve`，打开 `http://localhost:8010` 在线阅读（带目录和搜索，手机也能看）；
1. 先用 PDF 通读一章，建立该章的问题链；
2. 对照教材核对公式与推导，重点看“适用条件”标注；
3. 用分章节 PDF 做考前快速回顾；
4. 需要改写或补公式时用 docx 版（Word 原生公式）。

Word 版目录若显示为空，`Ctrl+A` → `F9` 更新域。
