# 知识点总结制作流程

从教材文本到可打印 PDF 的完整步骤。总结用的是「**提示词模板 + 每章单独大纲 + 配置驱动脚本**」，换科目只需换配置，不用改代码。

## 0. 准备

需要：

- `pandoc`、`xelatex`（TeX Live，含 `xeCJK`）、`Noto Serif CJK SC` 字体
- Python 3 + `python-docx`
- 调用模型的 CLI（本仓库默认用 DeepTutor 调 DeepSeek，可换成任意命令行 LLM）
- 可选：LibreOffice + `python3-uno`，用于自动更新 Word 目录

教材文本：把课本 OCR 成纯文本，一章一个区段，用**行号**记录每章起止（1-based，含首尾）。本项目里是 `elasticity_txt/elasticity_part1.txt`（教材原文有版权，不进仓库），章节标记写在配置里：

```json
{"key": "ch2", "title": "第二章 应力状态理论", "start_line": 505, "end_line": 1253}
```

## 1. 为每章写大纲

这是整套方法里最关键的一步。**不要用固定十板块模板**——固定模板会让每章长得一样，把本章真正的逻辑压平。每章单独给 7–9 条「问题链」，写法见 [`prompts/大纲怎么写.md`](prompts/大纲怎么写.md)。

大纲写进配置文件的 `chapters[].outline` 数组，每条一行，以 `- ` 开头。

## 2. 写配置

仿照 [`configs/elasticity.json`](configs/elasticity.json)：

| 字段 | 含义 |
|---|---|
| `book` / `edition` | 教材名与版本，会填进提示词 |
| `source_txt` | OCR 文本路径（相对配置文件目录） |
| `output_dir` | 生成 Markdown 的目录（本项目直接写进 `docs/弹性力学/`，同时作为阅读站点的内容） |
| `template` | 提示词模板 |
| `subject_rules` | 学科专用要求（如弹性力学的张量记号、适用前提） |
| `llm.cmd` | 调用命令，必须含 `{prompt}` 占位符 |
| `llm.response_mode` | `deeptutor_json` 解析事件流；其他 CLI 用 `stdout` |
| `chapters[]` | 章节键、标题、起止行号、大纲 |

> 相对路径都以配置文件所在目录为基准。`source_txt` 不在仓库里，需要自己放好。

## 3. 生成 Markdown

```bash
cd 方法与工具
PY=/root/deeptutor/.venv/bin/python

# 先只拼提示词，检查行号和长度（不调用模型）
$PY scripts/summarize.py configs/elasticity.json --dry-run

# 逐章生成；可指定章节，方便重跑单章
$PY scripts/summarize.py configs/elasticity.json ch1 ch2 ch3 ch4 ch5 ch6 ch7
```

脚本会：

1. 按行号切出本章原文；
2. 把 `{book}` `{edition}` `{outline}` `{subject_rules}` 替换进
   [`prompts/总结提示词模板.md`](prompts/总结提示词模板.md)；
3. 拼上「【章节原文】… 【输出】」；
4. 调用 `llm.cmd`，把回答写到 `output_dir/chN.md`。

> 本项目把 `output_dir` 指向 `docs/弹性力学/`：生成的 Markdown 既是排版源文件，也是阅读站点的页面。章节标题由 `mkdocs.yml` 的 `nav` 提供，正文保持 `##` 开头即可。

换用其他模型（任意 CLI）时，把 `llm.cmd` 改成对应命令，并把 `response_mode` 设为 `stdout`。

## 4. 人工审校

生成后**必须逐章检查**，至少看这几点：

- 公式符号、上下标是否与教材一致；
- 结论是否写清适用前提（小变形、线弹性、各向同性、平面应力/应变、单连通等）；
- 有没有教材里没有的「自由发挥」；
- 是否被截断（结尾不完整 → 调大输出上限后重跑该章）；
- 表格不超过 4 列、单元格里没有长公式（否则排版会挤）。

不合格就改大纲或补充 `subject_rules`，然后只重跑那一章。

## 5. 排版成 Word / PDF

```bash
cd 方法与工具
PY=/root/deeptutor/.venv/bin/python

TITLE="弹性力学 前七章知识点总结" \
SUBTITLE="依据 吴家龙《弹性力学》（第3版）" \
DATE="2026 年 11 月" \
bash scripts/render_all.sh ../docs/弹性力学 /tmp/elasticity_out 7
```

`render_all.sh` 依次做：

1. 用 `make_ref.py` 从 `ref_base.docx` 生成中文 Word 模板 `ref_zh.docx`
   （正文宋体 10.5pt / 1.5 倍行距，标题黑体，A4，3cm 左右边距）；
2. 每章 `convert_chapter.sh`：
   - 补上 `# 第N章 标题`；
   - `normalize_md.py` 给列表前后补空行；
   - pandoc → docx，公式转 Word 原生 OMML；
   - `fix_tables.py` 按内容重算表格列宽；
3. 每章 `build_pdf.sh`：pandoc + xelatex + `latex/header_zh.tex` → 单章 PDF（A4）；
4. `merge_md.py` 合并出 docx / pdf 两版整本 Markdown，再分别渲染成带封面目录的整本文件。

输出：`ch1.docx/pdf … chN.docx/pdf`，以及 `TITLE.docx` / `TITLE.pdf`。

## 6. 目录

- **PDF**：`merge_md.py --format pdf` 生成 LaTeX 分页；整本目录由 pandoc `--toc` 配合 `latex/template_zh.tex` 生成，页码自动正确。
- **Word**：目录是 Word 域代码。打开后 `Ctrl+A` → `F9` 更新；或装好 LibreOffice 后跑：

```bash
python3 scripts/update_toc.py in.docx out.docx out.pdf
```

注意 `update_toc.py` 依赖 `python3-uno`，要用系统 Python 而不是虚拟环境。

## 7. 阅读站点（MkDocs）

章节 Markdown 同时供 MkDocs 使用，站点配置在仓库根目录：

```bash
cd ..                 # 回到仓库根目录
bash site.sh serve    # 首次自动装 mkdocs-material，打开 http://localhost:8010
bash site.sh build    # 生成 site/
```

- `docs/弹性力学/pdf/` 由 `site.sh prepare` 从 `弹性力学/` 复制，已在 `.gitignore` 里；
- 公式走 MathJax 3，配置在 `docs/javascripts/mathjax.js`；标题里的 LaTeX 会单独再排一次目录；
- 搜索摘要里的公式源码由 `hooks/clean_search.py` 在构建后清掉，替换成省略号，避免结果里出现 `\(...\)`；
- 新增科目：正文放进 `docs/<科目>/`，写一个科目页 `index.md`，在 `mkdocs.yml` 的 `nav` 里加一节；首页 `docs/index.md` 的课程卡片手动加一张，右侧课程索引会从 nav 自动生成；
- 部署：推到 GitHub 后启用 Pages（`.github/workflows/pages.yml`），或把 `site/` 交给 nginx。Gitee 不适合直接托管静态站。

## 常见坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 列表的 `-` 变成正文符号、和上一段挤在一起 | 生成的 Markdown 列表前没有空行，pandoc 把列表吞进段落 | `normalize_md.py` 已自动补空行 |
| 表格长文本竖着排、列宽一样 | pandoc 默认等宽列 | `fix_tables.py` 按内容重算列宽，并设置不跨页、表头重复 |
| PDF 里公式的方括号变成竖线 | 用 LibreOffice 把 docx 转 PDF，OMML 渲染有缺陷 | PDF 一律走 xelatex，不要从 docx 转 |
| 长公式冲出页面 | 模型写了超宽公式链 | 提示词已限制；仍出现就手动换行或用 `\begin{aligned}` |
| Word 打开目录为空/页码不对 | 目录域未更新 | `Ctrl+A` → `F9` |
| PDF 中文变成方框 | 缺中文字体 | 安装 Noto CJK；模板里指定 `Noto Serif CJK SC` |
| 某章内容被截断 | 模型输出上限 | 调大 `llm` 的输出上限，单独重跑该章 |
| 行号错位、切章不准 | 文本换行或行号从 0 开始 | 先 `--dry-run` 看每章字符数，明显异常就修正 `start_line` / `end_line` |

## 归档到仓库

每门课一个目录，放：

- 整本 PDF、DOCX；
- `分章节/` 单章 PDF；
- 正文源文件放在 `docs/<科目>/`，附 `titles.txt`（每行 `ch1=绪论`）；
- 在 `方法与工具/configs/` 留一份该科目的配置，下次改大纲或补章节可直接重跑；
- 在 `mkdocs.yml` 的 `nav` 里加科目入口。

教材原文与扫描件不入库。
