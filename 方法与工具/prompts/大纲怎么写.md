# 各章大纲怎么写

大纲决定每章总结的骨架。它写得好，模型就能按本章知识自身的逻辑展开；写得空，模型就会退回「定义—方程—例题」的流水账。

## 核心原则

1. **大纲是问题链，不是教材目录。** 每条应回答“这一节要解决什么问题”，而不是罗列“基本概念、基本方程、典型例题”。
2. **7–9 条为宜。** 少于 5 条撑不起一章，多于 10 条会退化成细碎知识点清单。
3. **顺序体现依赖关系。** 通常是：为什么需要 → 核心量怎么定义 → 控制方程怎么来 → 定解条件 → 典型问题 → 结果特点与适用边界 → 易混点。
4. **必须包含本章特有的东西。** 例如极坐标那一章特有「两径向面法线不平行、两圆柱面面积不等 → 方程里出现 `1/ρ` 和 `(σρ−σφ)/ρ`」；这类条目是高质量总结与模板化总结的分水岭。
5. **不写空话。** “掌握基本概念”“了解工程应用”“重点难点”这类条目没有信息量，删掉。
6. **可以对齐教材节次，但不要照抄节标题。** 节标题常是名词短语，大纲要写成问题或推导线索。

## 每条怎么写

推荐句式：

- “X 从哪里来 / 为什么要引入 X”
- “X 的定义、符号、量纲、物理意义”
- “X 方程怎么推出来、在什么前提下成立”
- “边界条件怎么写、和基本方程如何组成定解问题”
- “典型问题：模型、已知、关键结论”
- “哪些结论只在特定前提下成立”
- “最易混淆的概念对及辨析”

## 示例：弹性力学第二章

```text
- 外力怎样进入物体：体力、面力（定义、符号、量纲、与内力的关系）
- 一点的应力：应力矢量的定义，斜截面上应力的柯西公式
- 应力张量：九个分量、切应力互等关系、正负号与指标规定
- 主应力与应力不变量：特征方程、三个不变量、主方向
- 最大切应力与应力圆（原文涉及则写）：主切应力、极值性质
- 应力场的控制方程：平衡微分方程、应力边界条件
- 分析范式小结：斜截面公式、转轴变换、主方向求解各解决什么问题
- 易混辨析：应力矢量与应力张量、正应力与切应力的符号约定
```

对应的总结会沿「外力 → 一点的应力 → 应力张量 → 主应力 → 平衡方程」这条链展开，而不是把定义和方程分块罗列。

## 示例：换一门课（振动力学·单自由度系统）

```text
- 振动问题怎么建模：为什么能把复杂结构简化为质量-弹簧-阻尼
- 无阻尼自由振动：固有频率从哪来，初始条件如何决定振幅与相位
- 阻尼的作用：欠阻尼/临界阻尼/过阻尼三种情形的判别与物理图像
- 简谐激励下的稳态响应：频率比与幅频/相频特性的读法
- 共振区的行为与阻尼的抑制机理
- 任意激励的响应：杜哈梅积分的思想与适用条件
- 等效质量、等效刚度的折算依据
- 易混辨析：固有频率与共振频率、静位移与动力放大系数
```

## 落地方式

大纲写进 `方法与工具/configs/<科目>.json` 的 `chapters[].outline`，每条一行：

```json
"outline": [
  "- 第一层问题：……",
  "- 第二层问题：……"
]
```

改完先跑 `summarize.py --dry-run` 看原文与提示词长度，再生成。
